# Attribution

Every asset and data source in FlightCraft is original or openly licensed, with one row here.
Rust crate dependencies are covered by the licence check (`cargo deny check licenses`), not listed here.

| Item | Source | Licence | Notes |
|---|---|---|---|
| Corvid geometry, coefficient tables, propulsion, and gear data | Original FlightCraft design | Apache-2.0 | Engineering estimates; each table documents its derivation in `aircraft/corvid.aircraft.json`. |
| ISA equations and reference values | US Standard Atmosphere 1976, NOAA/NASA/USAF; ISO 2533 atmosphere relationships | Public domain (US government publication) | Equations independently implemented; geopotential height, 0–20 km. |
| Airfoil design background | NACA Report 824 (1945), Summary of Airfoil Data | Public domain (US government publication) | Cambered four-digit section background only; no digitised coefficient data. |
| Corvid display mesh, training field geometry, and scene shaders | Original procedural artwork in `crates/render` | Apache-2.0 | Built in code; no external assets |
| Corvid cockpit frame, wing roots, struts, and propeller disc | Original procedural artwork in `crates/render` | Apache-2.0 | Fictional interior built in code |
| Flight instruments and interface artwork | Original painter geometry in `crates/ui` | Apache-2.0 | Built in code |
| Browser takeoff example (`apps/web/takeoff.jsonl`) | Original FlightCraft script, copied from `examples/takeoff.jsonl` | Apache-2.0 | Timed commands for the Corvid |
| Droid Sans (`crates/ui/assets/DroidSans.ttf`) | [Android Open Source Project](https://android.googlesource.com/platform/frameworks/base/), Droid fonts | Apache-2.0 | Copyright 2005–2008 The Android Open Source Project; bundled notice and licence in `crates/ui/assets/DroidSans-NOTICE.txt` |
| Dryden turbulence transfer functions and isotropic scale length | MIL-F-8785C (5 November 1980), §3.7.2; MIL-HDBK-1797 (19 December 1997), atmospheric turbulence model | Public domain (US government publications) | Filters independently derived and implemented in `crates/world/src/weather.rs`; intensity presets are original scenario choices. |
| Larrow geometry, coefficient tables, propulsion, and gear data | Original FlightCraft design | Apache-2.0 | Independent textbook lifting-line, strip-theory, tail-volume, and blade-element estimates; each table documents its derivation in `aircraft/larrow.aircraft.json`. |
| Larrow low-wing display mesh, single-seat canopy, cockpit, and tailwheel | Original procedural artwork in `crates/render` | Apache-2.0 | Built in code; no external assets. |
| Larrow takeoff example (`examples/larrow-takeoff.jsonl`) | Original FlightCraft script | Apache-2.0 | Tail raise, rotation, and climb using the shared command path. |
| Training valley height tiles (`assets/terrain/training-valley/`) | Original seeded landscape generated by `cargo xtask terrain` | Apache-2.0 | Analytic hills, a ridge, a lake, and a flattened airfield; no elevation source data. |
